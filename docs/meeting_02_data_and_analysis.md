# 运营 × 开发 会议记录 #2
## 核心议题：如何搜集有效数据 + 如何生成有意义的推送

---

### 【运营】先说现在的核心问题

跑了一周了，数据库才100多条视频，这说明数据采集层面就有根本问题。而且推送内容的价值基本等于零——和直接把热搜丢给豆包问一句"怎么蹭"没区别。

**如果一个工具跑了一周，给出的建议和随手问AI一句话一样，那这个工具就没有存在的意义。**

所以今天要解决两个根本问题：
1. 数据从哪来？怎么让数据量从100条变成每天1000条？
2. 拿到数据后怎么分析才能给出"豆包给不了"的建议？

---

### 【开发】先承认问题

现在的数据采集逻辑是：
- 8个同行账号 × 每次10条 = 80条（但大部分是重复的旧视频）
- 热搜50条（只有标题，没有对应的视频内容）

所以实际有效新数据每天可能只有不到10条。这确实太少了。

### 【运营】问题出在哪？

**问题1：只采集了"已知账号"的视频**

我们只盯着8个已知的同行。但抖音上做手工的账号成千上万，真正的爆款往往来自我们不认识的人——一个500粉的新人发了条视频突然爆了，这才是最有价值的信号。

**问题2：热搜分析只看了标题**

我们拿到50条热搜标题，丢给AI问"能不能蹭"。但热搜标题和手工99%没关系，所以AI基本每次都回"没有"或者硬蹭。

**正确的做法应该是：不看热搜标题，而是搜手工相关的关键词，看这些关键词下面最近什么视频在涨。**

### 【开发】你说得对。让我重新设计数据采集逻辑

**现在的逻辑（错的）：**
```
热搜标题 → 问AI"能蹭吗" → 大部分回"不能" → 浪费
8个同行 → 看最新视频 → 都是老视频 → 没用
```

**应该改成的逻辑：**
```
关键词"风琴本" → 搜最近一周的视频 → 按点赞排序 → 发现全网风琴本最火的视频
关键词"手账"   → 搜最近一周的视频 → 按点赞排序 → 发现全网手账最火的视频
关键词"手工本" → 同上
... 7个关键词 → 每个20条 → 140条全网精选视频

从这140条里找：哪些是最近几天发布的？哪些涨得特别快？
这些才是我们真正要分析的"起势视频"。
```

### 【运营】完全正确！这才是有用的数据

而且这140条视频不是8个人的，是全网几万个手工博主的。覆盖面完全不一样。

**关键词搜索才是这个项目的核心引擎，而不是热搜分析。**

热搜分析可以保留作为辅助，但权重应该从现在的"主角"降为"配角"。

### 【开发】那数据采集优先级重新排

```
每次采集（1小时一次）：

优先级1：关键词搜索（核心引擎）
  - 搜7个关键词，每个取最新20条
  - 每次产生 ~140 条视频
  - 和上次对比，找出新增的高赞视频
  - 对新发现的起势视频做深度分析

优先级2：同行监控（补充）
  - 2小时一次
  - 不是看他们发了什么，而是看"他们在蹭什么话题"
  - 提取他们最新视频的标题关键词，作为新的搜索词

优先级3：热搜（辅助）
  - 保留采集，但不再做AI分析
  - 只在早报里展示热搜排行，供人工判断
```

### 【运营】对。那我们再讨论第二个问题：怎么让AI分析有价值

现在的AI分析等于：
```
输入：视频标题 + 四维数据（赞/评/藏/分）
输出：为什么火 + 怎么蹭 + 标题建议
```

这和直接问豆包没区别，因为**输入信息太少了**。AI不知道视频具体拍了什么，不知道评论区在聊什么，不知道作者是谁，不知道用了什么BGM。

### 【开发】要让AI分析有价值，核心是给它更多信息

能补充的信息有：

| 信息 | 获取方式 | 价值 |
|------|---------|------|
| 热门评论TOP20 | 评论接口 `/comment/list/` | 极高——知道用户真正关心什么 |
| 视频描述/话题标签 | 搜索结果里已有 | 高——知道作者用了什么标签 |
| 作者粉丝量 | 用户信息接口 | 中——500粉爆了比50万粉爆了更值得关注 |
| 同类视频的平均数据 | 数据库里已有 | 中——知道这条是不是真的超常 |

**评论采集是关键**。没有评论，AI就是在猜；有了评论，AI能看到真实的用户反馈。

### 【运营】具体来说，有了评论后AI能做什么不一样的事？

**没有评论时AI说：** "这条视频迷你化+治愈感的双重杀手锏"（废话）

**有了评论后AI能说：**
```
评论区300+人问"教程在哪" → 说明这个品类缺教程，你出教程很可能爆
评论区200+人说"想买" → 说明有带货需求，可以在视频里挂链接
评论区150+人说"送闺蜜" → 说明送礼场景，标题可以往送礼方向写
评论区有人说"比xx店的好看" → 说明有价格优势，可以对标
```

**这才是"豆包给不了"的分析——因为豆包不知道评论内容。**

### 【开发】技术实现方案

视频评论接口：
```
GET /aweme/v1/web/comment/list/
参数：aweme_id, count=20, cursor=0
返回：评论文本、点赞数、回复数
```

这个接口需要Cookie但不需要a_bogus（和用户视频列表一样的模式）。

**AI分析的新prompt应该是这样的：**

```
我女朋友做风琴本/尼泊尔手工本/手账。

这条视频正在起势：
- 标题：xxx
- 作者：@xxx（粉丝 5000）
- 发布6小时，已获 2.3万赞
- 收藏率 8%（远高于平均3%）

热门评论（按点赞排序）：
1. "教程在哪！！跪求"（赞 350）
2. "材料链接发一下"（赞 280）
3. "做一个送女朋友"（赞 200）
4. "这个比xx店卖的好看多了"（赞 180）
5. "手残党能学会吗"（赞 150）

请分析：
【用户需求】评论区反映出什么需求？（教程？购买？送礼？）
【机会判断】这个品类/风格现在是什么阶段？（早期/爆发/饱和）
【具体建议】我女朋友可以怎么做？给出：
  - 拍什么内容（教程？制作过程？开箱？对比？）
  - 多长时长
  - 标题怎么写（参考这条火的标题结构）
  - 什么时间发（根据这条的发布时间推测）
```

### 【运营】这个输入信息量就完全不一样了

AI拿到这些信息后能给出真正有操作价值的建议。比如：

```
【用户需求】
评论区主要需求是"教程"和"购买"。350人求教程说明这个品类
教程内容严重不足，是蓝海。280人问材料链接说明有带货空间。

【机会判断】
作者才5000粉就能6小时2.3万赞，说明这个内容本身质量过硬，
不是靠粉丝基数撑起来的。风琴本挂件这个细分品类目前内容
少、需求大，正处于早期爆发阶段。

【具体建议】
1. 出一条"风琴本挂件教程"，30-45秒，前3秒展示成品
2. 用尼泊尔手工纸做差异化（原视频用的是普通纸）
3. 标题参考这条的结构：动作+情感词
   → "用尼泊尔手工纸做风琴本挂件｜成品太惊艳了"
4. 今晚8-9点发（这条是下午发的，晚上发可能流量更好）
5. 评论区引导"要教程的扣1"，带动互动率
```

### 【开发】明白了。那总结一下具体改动

**采集层改动：**
1. `douyin.py` 加 `search_videos(keyword, sort_type, publish_time)` — 关键词搜索
2. `douyin.py` 加 `get_video_comments(aweme_id, count=20)` — 评论采集
3. `database.py` 加 `keyword_searches` 表 — 存搜索结果
4. `collect.py` 重构采集流程 — 关键词搜索为核心

**分析层改动：**
5. `ai_analyzer.py` 重写 `analyze_trending_video()` — 输入评论数据
6. AI prompt 大幅升级 — 用户需求分析、机会判断、具体操作建议

**推送层改动：**
7. `notifier.py` 新增 `send_keyword_discovery()` — 关键词发现推送
8. 推送格式改版 — 包含评论摘要和操作建议

**频率调整：**
9. 热搜AI分析 → 降为辅助，不再主动推送，只放在早报里
10. 关键词搜索 → 每2小时一次，发现起势视频才推送
11. 同行监控 → 每4小时一次

### 【运营】最后一个问题：推送应该长什么样？

**旧的推送（没用）：**
```
📈 热搜蹭热度机会
1. 酱油洗洁精拉花 → 画进手账里
```

**新的推送（有用）：**
```
🔍 关键词「风琴本」发现起势视频

🔥 风琴本挂件制作过程 | 超治愈
@手工小白日记（粉丝 5000）
发布 6 小时 → 赞 2.3w | 评 892 | 藏 5.1k
收藏率 8%（平均 3%）

💬 评论区热词：
求教程(350赞) | 材料链接(280赞) | 送女朋友(200赞)

🧠 AI 分析：
- 用户最大需求：教程（350人求教程，说明这个品类教程严重不足）
- 机会阶段：早期爆发（小粉丝账号也能爆，说明内容缺口大）
- 建议做法：出一条30秒教程，用尼泊尔纸做差异化
- 标题参考：用尼泊尔手工纸做风琴本挂件｜成品太惊艳了
- 发布时间：今晚8-9点

🔗 查看原视频
```

**这条推送包含了：原视频数据 + 评论区洞察 + AI操作建议。**
**这是豆包给不了的，因为豆包不知道评论内容，也不知道你的赛道数据。**

## 会议结论

### 根本性方向调整

| | 旧方案 | 新方案 |
|---|---|---|
| 核心引擎 | 热搜AI分析 | **关键词搜索** |
| 数据源 | 8个同行 + 热搜标题 | **全网关键词搜索 + 评论采集** |
| 每日数据量 | ~10条新视频 | **~140条精选视频** |
| AI分析输入 | 标题+四维数据 | **标题+数据+评论+作者信息** |
| AI分析输出 | "迷你化+治愈感" | **用户需求+机会判断+具体操作** |
| 推送频率 | 每小时推热搜分析 | **有起势视频才推，没有就安静** |

### 执行优先级

1. **关键词搜索** — 先验证接口是否可用（5分钟）
2. **评论采集** — 加接口
3. **AI prompt 升级** — 带评论数据分析
4. **推送格式改版** — 包含评论摘要
5. **热搜降级** — 只放在早报里
